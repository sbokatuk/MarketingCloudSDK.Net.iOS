## What's changed

First release of the rebuilt binding, at the v11 Unified SDK generation.

- Binds **MarketingCloudSDK 11.0.2** (was 8.x in the retired `sfmc-net-bindings-mobile`
  packages) and ships the new **AppGroupSDK 1.0.0** requirement as a payload-only sibling
  package, both fetched from tag archives with per-binary SHA-256 pins.
- Depends on **SFMCSDK.Net.iOS 4.0.1.1** for the core, mirroring the native package manifests.
- The hand-curated `ApiDefinitions.cs` was ported 8.1.x → 11.0.2 by header diff with a
  bidirectional selector-parity check; the packed binding passes live simulator smoke tests,
  including the module-configured initialization completion.
- Migrating from `8.x`: the `sfmc_*` category class is now `MobilePushSDK`;
  `PushConfig(Builder)`/`SFMCSdkPushModule` became `SFMarketingCloudSdkConfig(Builder)` +
  `SFMarketingCloudSdk` attached via `SFMCSdkConfigBuilder.SetPushFeature`; the URL-handling and
  event delegates are replaced by the v4 SFMCSDK event surface fed through the new
  `sfmc_handle*Event:` hooks; device-token/notification-request setters left the category
  surface (readers remain).
